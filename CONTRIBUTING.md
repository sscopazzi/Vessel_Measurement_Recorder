# Contributing

Contributions are welcome. Each one is accepted under the licence of the files it changes (see
`LICENSE`). Sign off every commit (`git commit -s`). Signing off certifies the Developer Certificate of
Origin 1.1 (https://developercertificate.org): you wrote the change, or otherwise have the right to
submit it under these licences. New files need an SPDX header, or an entry in `REUSE.toml`. Do not
change `teos10.c` or `gsw_internal_const.h`.
